1. **NEXUS - Unified Assistive Technology Interface**
*Designed activity-based interface transforming fragmented AT systems into seamless experience for children with quadriplegic cerebral palsy. Built React Native prototype integrating eye-gaze tracking, switch access, and voice commands. Increased functional independence from 10% to 80% through user research with families and clinicians.*
**Tech Stack:** React Native, TypeScript, WebGazer.js, Firebase, PostgreSQL, TensorFlow.js
**Impact:** 3-5 family pilot, 80% independence increase
**Link:** https://access-nexus.netlify.app/


2. **FinAbility - Financial Tool for Cognitive Accessibility**
*Mobile banking app promoting financial independence for adults with intellectual disabilities. Features simplified categorization, plain-language explainer (GPT-4), decision support, and practice mode with fake money. Supported autonomy framework maintains user control while enabling view-only helper access.*
**Tech Stack:** React Native, Node.js, Plaid API, OpenAI API, PostgreSQL
**Impact:** 8-10 participant pilot, improved financial capability scores


3. **Co-Create AI - Human-AI Creative Partnership**
*Experimental platform exploring five human-AI collaboration models in digital art. Modes include AI as Tool, Turn-Taking, AI as Muse, Negotiated Creation, and Real-Time Co-Creation. Study with 15-20 artists measuring creativity, authorship perception, and mode preferences generated design guidelines for creative AI tools.*
**Tech Stack:** React, Stable Diffusion, DALL-E 3, GPT-4, Socket.io, MongoDB
**Impact:** 15-20 artists, 75+ artworks, published design guidelines


4. **Little Luxuries - Treatonomics Visualization**
*Analyzed "treatonomics" - consumer behavior maintaining small indulgences during economic uncertainty. Preprocessed 500K+ transactions from e-commerce and retail data (2020-2025). Built interactive Tableau dashboards testing whether the "lipstick effect" holds and identifying modern recession indicators.*
**Tech Stack:** Python (Pandas, NumPy), Tableau, FRED API
**Impact:** 500K+ transactions analyzed, 5-year trend analysis
**Team:** 3-person collaboration
